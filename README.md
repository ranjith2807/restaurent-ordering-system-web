# 🏍️ Moto Café — Restaurant Ordering System

A biker-themed restaurant ordering web application featuring a dark garage aesthetic, glassmorphism UI, interactive digital menu, and real-time cart/checkout flow.

---

## ✨ Features

- **Dark Garage & Biker Theme**: Custom ambient glow effects, industrial badges, and sleek typography.
- **Interactive Food & Drink Menu**:
  - Category filters (Burgers, Artisanal Roasts, Wood-Fired Pizza, Pit Snacks, Shakes & Drinks).
  - Search bar and dietary tags (Vegetarian, Chef's Special, Spicy).
  - Quick add-to-cart with customizable options.
- **Dynamic Fuel Cart**:
  - Offcanvas slide-out cart drawer.
  - Live quantity adjustment and item removal.
  - Subtotal, taxes, and grand total calculations.
- **Interactive Checkout Flow**:
  - Modal checkout form for dine-in, takeaway, or rider delivery.
  - Table number / delivery address selector.
  - Instant order summary and confirmation.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Styling & Icons**: Bootstrap 5, Bootstrap Icons, Google Fonts (Oswald & Plus Jakarta Sans)
- **Local Server**: Node.js HTTP Server (`server.js`)

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ranjith2807/restaurent-ordering-system-web.git
cd restaurent-ordering-system-web
```

### 2. Run the application
Using Node.js:
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your web browser.

Alternatively, you can open `index.html` directly in any modern browser.
